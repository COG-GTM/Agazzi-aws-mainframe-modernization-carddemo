# modern/frontend — CardDemo SPA (owner: O6 `o6-frontend`)

React 18 + TypeScript (Vite) replacement of the 3270 BMS screens (plan §3.2, Fase 3).
Not a Maven module: own `package.json`, build and tests (Node ≥ 20).

```bash
npm ci
npm test          # tsc + vitest: unit, BMS golden, contract tests against a Prism mock of openapi.yaml
npm run build     # dist/
npm run mock      # Prism mock of openapi.yaml on :4010
npm run dev       # Vite on :5173, proxies /api to $CARDDEMO_API (default Prism :4010; carddemo-app = http://localhost:8080)
npm run gen       # regenerate src/generated/ (api.d.ts from openapi.yaml, bms-layouts.json from app/**/bms/*.bms)
```

## How it works
- **Client**: `src/generated/api.d.ts` is generated by `openapi-typescript` from
  `carddemo-contracts/src/main/resources/openapi/openapi.yaml` (contracts-v1); `src/api/client.ts` wraps it with
  `openapi-fetch` (`credentials: include` for the server-side session cookie, ADR-002).
- **Pseudo-conversation**: GET `/api/v1/screens/<mapset>` = first send, POST = AID key + unprotected fields.
  `nextScreen` (mapset/map/program/transid) triggers an XCTL (GET of the target); `null` = same screen.
  401 → back to COSGN00, 403 → ERRMSG.
- **Layout**: `scripts/gen-bms-layouts.mjs` parses every `DFHMDF` (named fields and literals) of the legacy BMS
  (read-only) into `src/generated/bms-layouts.json`; `Terminal3270` renders a 24×80 grid (data starts one column
  after `POS`, the attribute byte), colours from `COLOR=` or the 3270 base defaults, `HILIGHT=UNDERLINE`, `BRT`,
  `DRK` (password / hidden), `NUM`, `IC` (initial cursor), `JUSTIFY=RIGHT`, auto-skip when a field is full.
  `messages`/`fieldErrors` go to the ERRMSG/INFOMSG lines and highlight the field (cursor on the first error).
- **One view per `ScreenId`** (`src/screens/views.ts`, mirror of `ScreenId.java` checked by tests).
- **PF keys**: Enter=ENTER, Esc/Pause=CLEAR, F1–F12=PF1–PF12 (also Alt+F1–F12), Alt+1/Alt+2=PA1/PA2, plus an AID button bar.
- **Extensions X1/X2** (COPAU*, COTRT*) are off unless `VITE_CARDDEMO_EXT_AUTHORIZATION` /
  `VITE_CARDDEMO_EXT_TRANTYPE` = `true` (or `window.__CARDDEMO_FLAGS__` at runtime), like `carddemo.extensions.<name>.enabled`.

## Tests
- `tests/unit`: components, PF keys, flags, App flow (fake API), registry vs `ScreenId.java`, OpenAPI DTOs vs BMS
  layouts (Input = unprotected fields, maxLength = LENGTH, row/col).
- `tests/golden`: generated layouts up to date; named fields equal `docs/inventory/bms.md`; 24×80 text rendering
  of each map equals `tests/golden/screens/<MAPSET>.txt` (`UPDATE_GOLDEN=1 npm run test:unit` to regenerate).
- `tests/contract`: starts Prism from `openapi.yaml` and drives the generated client for every screen
  (GET, POST × every AID key with full-length fields), checks request validation and 401/403 mapping.
